# 数据预处理工作台

一个**完全本地运行**的 Excel / CSV 数据预处理网页工具：双击 `index.html` 用 Chrome / Edge 打开即用，不联网、不登录、不部署，数据只存在你自己的电脑上。

## 一、解决什么问题

课程作业、竞赛、项目里的原始数据通常是"脏"的：有重复行、缺失值、文本型数字、异常值，还要做多表合并。用代码清洗门槛高，用 Excel 手工改又容易出错、改乱了还查不回去。

这个工具让不懂编程的人也能**安全、可控、可追溯**地完成数据清洗：

- 每一步操作前先预览"将影响几行几列"，确认无误再执行
- 原始文件永远不会被修改，导出的一律是 `*_cleaned` 新文件
- 每一步都自动写处理日志（时间、规则、影响量），可随结果导出备查
- 高风险操作（删异常值、大量缺失删除、N:N 合并等）会强制暂停并二次确认

## 二、主要功能

**九个清洗模块**（按推荐顺序排列）：

| 模块 | 说明 |
|------|------|
| 读取与查看 | 数据体检报告：行数、列数、重复行数、每列缺失率与疑似问题提示，点击列名展开分布详情 |
| 重复值 | 按整行或指定列判重，保留第一条 / 最后一条，删除前预览标红 |
| 缺失值 | 每列缺失率可视化；按列选删行 / 删列 / 均值 / 中位数 / 众数 / 前后向填充 / 固定值，支持批量套用 |
| 异常值 | IQR / Z-score / 自定义业务区间检测；默认新增 `*_outlier_flag` 标记列不删行，删除需填理由并二次确认 |
| 类型转换 | 修正"文本型数字"等类型问题；转换前预演成功 / 失败行数及失败示例 |
| 特征工程 | 四则运算、条件生成（if-then）、日期拆解、文本提取、分箱（等宽 / 等频 / 自定义区间）派生新列 |
| 类别编码 | One-Hot 编码、顺序编码（可自定义次序如 低<中<高），显示编码映射表 |
| 字段筛选 | 勾选保留列、拖拽调序、按条件筛行，实时显示"将保留 X 行 Y 列" |
| 多文件合并 | 两表按关联列合并，**合并前自动诊断 1:1 / 1:N / N:1 / N:N 关系与匹配率**，N:N 强制确认 |

**通用能力**：

- 影响预览条：每个模块执行前必显示本步影响范围
- 撤销上一步、步骤进度指示
- 全部数据存浏览器 IndexedDB，刷新 / 关闭浏览器 / 重启电脑后自动恢复工作区
- 一键导出 / 导入 `.json` 工作区备份（防浏览器缓存被清理）
- 依赖库（SheetJS）已内置在 `vendor/`，断网状态全功能可用

## 三、安装方法

**使用工具：无需安装。**

1. 下载或克隆本仓库
2. 双击 `index.html`，用 Chrome / Edge 打开即可（推荐 Chromium 内核浏览器，导出到指定文件夹依赖 File System Access API）
3. 请勿使用无痕模式（无痕模式不保留 IndexedDB，工作区无法持久化）

**运行测试：需要 [Node.js](https://nodejs.org/)。**

```bash
node test/run.js
```

## 四、使用方法

标准清洗流程：

1. **上传文件**：拖拽或点击选择 `.xlsx / .xls / .csv`（支持多 sheet 切换，几万行以内体验最佳）
2. **看体检报告**：系统自动生成，了解缺失、重复、类型等整体问题（未生成体检报告前，清洗类模块会被拦截）
3. **按模块顺序清洗**：去重 → 补缺失 → 处理异常 → 类型转换 → 特征工程 → 编码 → 字段筛选 → （可选）多表合并
4. **每步确认影响预览**：底部预览条显示"将影响 X 行 Y 列"，确认后执行
5. **导出结果**：导出文件自动命名为 `原名_cleaned_时间戳.xlsx`，可附带"处理日志"sheet；日志也可单独导出

误操作用底栏"撤销上一步"回退；换电脑或防缓存清理，用顶栏"导出备份 / 导入备份"。

## 五、输入输出示例

**输入** `students.csv`（含典型脏数据）：

| 姓名 | 成绩 | 注册日期 |
|------|------|----------|
| 张三 | 88 | 2026/1/3 |
| 张三 | 88 | 2026/1/3 （整行重复） |
| 李四 | （空） | 2026-01-05 |
| 王五 | "92"（文本型数字） | 2026/1/6 |
| 赵六 | 210（异常高） | 2026/1/7 |

**处理过程**：

1. 体检报告：提示 1 行重复、成绩列 1 个缺失、成绩列为"纯数字文本"
2. 重复值模块：按整行判重，删除 1 行（保留第一条）
3. 缺失值模块：成绩列填充中位数 → 90
4. 类型转换：成绩列文本 → 数字（预演显示 4 行成功、0 行失败）
5. 异常值模块：IQR 检测出 210 为可疑值，新增 `成绩_outlier_flag` 标记列（不删行）
6. 特征工程：从注册日期拆出 `注册月`、`星期` 两列

**输出**：

- `students_cleaned_20261015-183045.xlsx`：清洗后的 4 行数据 + 新增标记列、派生列，可选附带"处理日志"sheet
- 原始 `students.csv` 未被修改
- 处理日志示例条目：`2026-10-15 18:29 ｜ 缺失值填充 ｜ 成绩列填中位数(90)，影响 1 行`

## 项目结构

```
├── index.html          # 入口页面（五区域布局：顶栏/导航/工作区/日志/底栏）
├── css/style.css
├── js/core/            # 核心计算层（体检、去重、缺失、异常、类型、特征、编码、筛选、合并、步骤链）
├── js/ui/              # 界面层（视图、持久化、工具）
├── vendor/             # 本地化第三方库（SheetJS xlsx）
├── test/               # 测试（node test/run.js 运行）
└── PRD.md              # 产品需求文档（开发依据）
```

## 技术栈

原生 HTML / CSS / JavaScript，无框架、无构建；Excel 解析用本地内置的 [SheetJS](https://sheetjs.com/)；持久化用浏览器 IndexedDB；文件导出用 File System Access API（不支持时自动退回浏览器下载）。
